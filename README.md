# Jogo da Memória

Este projeto foi desenvolvido utilizando Vanilla JS, com HTML, CSS e JavaScript puros.

## Descrição

É um jogo da memória simples, no qual o jogador precisa encontrar os pares de cartas iguais. O objetivo é virar duas cartas por vez, memorizar sua posição e combinar todos os pares antes que o tempo termine ou até completar o tabuleiro.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Tabuleiro de cartas embaralhadas
- Verificação de pares
- Contador de movimentos
- Feedback visual ao acertar ou errar
- Jogo simples e responsivo

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. O jogo será carregado automaticamente.

## Objetivo

Completar todos os pares de cartas e testar sua memória.
